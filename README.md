# SailPoint Identity Security Cloud Workflows

## Theory, Design, and Engineering Guide

**Created and maintained by TedxHarry**

Welcome to the SailPoint ISC Workflows learning guide.

This course builds a strong understanding of how workflows operate in SailPoint Identity Security Cloud before moving into practical implementation and troubleshooting.

## Course Structure

### Foundations
Understand what workflows are, how they execute, and where they fit within ISC.

### Triggers
Learn how workflow events start a workflow and what information trigger payloads provide.

### Actions
Understand the operations workflows can perform.

### Logic
Learn how operators, comparisons, branching, and related logic control workflow execution.

### Data
Understand variables, expressions, trigger payloads, and action outputs.

### Testing and Debugging
Learn how workflow executions are tested, inspected, and troubleshot.

### Design
Learn when workflows are appropriate and how to design maintainable workflow solutions.
