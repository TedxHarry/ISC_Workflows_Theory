# Module 10: Real-World Workflow Patterns

Recognize reusable Workflow shapes, adapt them to real requirements, and distinguish Core, Working Engineer, and Advanced patterns.

This module is divided into shorter reading units so you can stop at a natural checkpoint without losing the full technical depth.

## Reading path

1. [Module 10.1: Pattern Method & Core Patterns](10-1-pattern-method-and-core-patterns.md)
   Learn the seven-part pattern anatomy and apply it to the Core pattern library.
2. [Module 10.2: Working Engineer Patterns](10-2-working-engineer-patterns.md)
   Apply the pattern method to access, account, approval, collection, and certification orchestration.
3. [Module 10.3: Advanced Patterns & Pattern Transfer](10-3-advanced-patterns-and-pattern-transfer.md)
   Recognize advanced security and integration patterns, combine shapes, and practice transferring patterns to new requirements.

**Start here:** [Module 10.1: Pattern Method & Core Patterns](10-1-pattern-method-and-core-patterns.md)

The numbered parts are one module. Read them in order on a first pass; return directly to a part later when you need it as a reference.
